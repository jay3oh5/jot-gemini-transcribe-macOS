# Quill's Copywriting Journal

## 2026-03-07 - Product Fork Brand Consistency in User Onboarding
**Learning:** In open-source forks rebranded from an upstream product (e.g. Sayo forked from Jot), technical identifiers and internal namespaces (`JotCore`, `JotUI`, bundle identifiers) intentionally remain intact for stability, but user-facing microcopy in onboarding flows (such as permission rationale, hardware status prompts, and headline instructions) must consistently use the product's actual name. Inconsistent brand naming in setup prompts causes immediate friction and confusion, degrading trust before the first dictation.
**Action:** Audit all user-facing strings in onboarding, error messages, and modal flows to ensure the app's current name is used consistently wherever the user reads about the product's identity or actions.
